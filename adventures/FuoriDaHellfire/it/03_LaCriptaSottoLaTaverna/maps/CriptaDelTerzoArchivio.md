# La Cripta del Terzo Archivio: Mappa DM

1 quadretto (qd) = 1,5m / 5ft.

## Layout

```
[INGRESSO] atrio palazzo storico, muro da sfondare (PF 10, CA 15)
    |
[1. Discesa] scalini, 2×4 qd
    |
[2. Corridoio] 13×2 qd, nicchie ai lati, trappola al 7° qd
    |
    ├── [4. Cucina] 3×3 qd, Chef Morticcio
    |
    ├── [3. Sala comune] 5qd Ø, 6 scheletri (3+3) + 1 ghast al centro
    |         |
    |    [6. Cella sigillata] 2×2 qd, porta ferro, tomba Aldric Sr.
    |
    └── [5. Biblioteca] 3×2 qd, registro sul leggio
```

## Note

- Percorso: scale → corridoio → andito a tre vie (cucina, sala comune, biblioteca).
- La cella sigillata è accessibile dalla sala comune (porta di ferro, chiave trovata nella sala stessa).
- Buio totale. Nessuna luce naturale.
- Pietra grigia lavorata, soffitto a volta basso (2 qd).
